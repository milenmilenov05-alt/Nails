# График Нокти

Публично уеб приложение за график на часове за маникюр. Приложението се публикува чрез GitHub Pages.

Записите се съхраняват само в локалното хранилище на браузъра и не се синхронизират между устройства. Използвай бутоните за бекъп и възстановяване, за да прехвърлиш или запазиш данните си.
